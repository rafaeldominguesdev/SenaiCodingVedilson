## Blockquotas (Citações)
As citações em markdown são criadas usando o sibolo de maior (`>`). Elas podem ser simples ou aninhadas:

> Está é uma citação simples.
> Está é uma sitação Aninhada

## Blocos de código
Blocos de código  são criados usando três crases (```) antes e depois do código.  Você também pode especificar a linguagem para habilitar o syntax high highlightign

### Python
```python
def ola_mundo():
        print("Olá, mundo!")
```

### SQL
``` sql
SELECT * FROM tb_aluno;
```

## Código Inline

Para inserir código inline dentro de um parágrafo, use uma única crase (`) ao redor do código.

Por exemplo, `print("Olá, mundo!)`
um exemplo de código inline em Python.

## Dicas adicionais
- Use blocos de código para trechos maiores e mais complexos
- Use código inline par apequenos trechos dentro de textos
- Sempre especifique a linguagem nos blocos de código para melhor legibilidade
