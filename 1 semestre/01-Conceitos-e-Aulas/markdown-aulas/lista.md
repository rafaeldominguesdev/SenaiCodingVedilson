# Lista e Organização
- Listas ordenadas e não ordenadas
- Listas aninhadas 
- Listar de tarefa

## Listas Ordenadas e Não ordernadas
As listas ordenadas e não ordenadas são usadas para organizar informações de forma clara e consisa. Aqui estão as principais diferenças entre elas :
- Listas ordenadas ( numeradas ) 
são usadas para quando a ordem dos itens é importante. Exemplo:

    1. Primeiro 
    2. Segundo item
    3. Terceiro item
- Listas não ordenadas (com macarcadores) são usadas quando a ordem dos itens não é importante Exemplo :
    - Item A
    - Item B
    - Item C
## Listas Aninhadas
 Lista aninhadas são listas dentro de outras listas. Elas podem ser usadas para criar subcategoria ou detalhar itens. exemplo :

 - Frutas
    - Maçã
        - Abacate
        - Tomate
    - Vegetais
        - Cenoura
        - Alfaca
            - Tomate

1. Frutas
    1. Maçâ
    2. Acabate
    3. Tomate

2. Vegetais
    1. Cenoura
    2. Alfacate
    3. Tomate

## Lista de Tarefas (CheckBox)
Listas de tarefas são usadas para acompanhar o progresso de atividades. Elas podem ser criadas usando colchetes. Exemplo :

- [x] Tarefa 1 
- [ ] Tarefa 2
- [ ] Tarefa 3
