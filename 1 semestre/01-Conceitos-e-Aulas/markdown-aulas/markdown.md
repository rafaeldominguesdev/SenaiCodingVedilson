## Headers (H1 a H6 )
Os hearders em markdown são utilizados para definir a hierarquia de títulos em um documento. Eles vão de H1 a H6,
sendoo H1 o título mais importante e H6 o menos importante.
Abaixo estão alguns exemplos
´´´ markdown

# Título H1
## Título H2
### Título H3
#### Título H4
##### Título H5
###### Título H6


## Boas práticas de estruturação 
- Use apenas um H1 por documento  para o título principal.
- Utilize H2 para secções principais e H3 para subseções
- Evite pular niveis de Headers ( por exemplo, nõ vá do H1 direto para o H3).

## Diferença entre "#", "-" e "="
Em Markdown, existem diferentes maneira de criar títulos, e cada uma tem suas particularidades:

- O símbolo "#" é usado para criar headers de H1 a H6, conforme a quantidade;
- O símbolo "=" é usado para criar títulos H1 quando colocado abaixo do texto.
- O símbolo "-" é usada para criar títulos H2 quando colocado abaixo do texto.

Exemplos de "=" e "-" 

Título 1
===

Título 2 
---
