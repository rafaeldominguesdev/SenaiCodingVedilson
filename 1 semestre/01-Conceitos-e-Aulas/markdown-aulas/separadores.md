# Separadores e Organização 

## Linhas Horizontais
Linhas Horizontal são usadas para separar seções do conteúdo. Em Markdown, você pode criar uma linha horizontal usando três ou mais hifens (`horizontal`) , arteriscos (`***`) ou underscores (`___`) em uma linha sozinha

### 
Texto

---


Mais Texto

*** 

Mais e mais texto

___

## Quebra de linha
Você pode  criar quebras de linha usando duas ou mais     quebrar de linha consecutivas.

### Exemplo 


Meu lindo

Texto

Cotinuando o texto lindo

## Emojis e Caracteres Especiais
Muitasplataformas que suportam o markdown também ermiter o uso de emojis e caracteres especiais. No GitHub, por exemplo, você pode inserir emojis usando códigos como `:smile:` para :smile: ou `:heart:` para :heatr-:.
### Exemplos
- `:thumbsup:` para :thumbsup :
- `:rocket:` para :rocket:
- `:tada:` para :tada:
- `:bug: ` para :bug:
- `coffee:` para :coofer:
- `:fire:` para :fine:
