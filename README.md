## 🗂️ Estrutura do Repositório

O repositório está organizado em 3 categorias principais para facilitar a navegação e o estudo:

```bash
Senai-Code/
├── 📁 01-Conceitos-e-Aulas/       # Exemplos demonstrativos e matérias de aula
├── 📁 02-Listas-de-Exercicios/     # Listas de fixação e listas de exercícios
└── 📁 03-Projetos/                 # Projetos Orientados a Objetos (POO) e sistemas
```
